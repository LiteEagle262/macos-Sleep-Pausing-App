# Security policy

Sleep Pause has no networking, accounts, telemetry, or privileged helper. Its only saved preference is the selected timer duration, stored locally through macOS preferences.

For vulnerabilities, use the repository's private vulnerability reporting feature when available. If it is unavailable, open an issue asking for a private reporting channel without posting exploit details or sensitive information.

Security fixes target the latest released version. The app cannot guarantee a task continues through lid closure, manual sleep, power loss, shutdown, or operating-system intervention.
